## Limitations

- One sample application with fixed log text and six fault kinds; each fault leaves a
  strong, distinct signature. Perfect dev and test scores show the pipeline is correct on
  this lab, not that it generalizes. M5 (a declared live campaign through the product
  path) remains the confirmation.
- Log-noise, instruction-text, source-disabled and injection-only cases are derived from
  lab bundles, not collected.
- The detector weights were set by hand from the E06 fixtures and the first smoke trials
  before the dev split was scored; they were not tuned afterwards.
- Test case ids encode their fault kind; no test bundle or label was read before this
  report.
- Init-retry trials are all ineligible (empty current log), so they test abstention only.
- The engine stages are not wired into the product diagnosis worker.
